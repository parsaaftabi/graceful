# Security Policy

## Supported versions

Only the latest release gets security fixes.

| Version | Supported |
| ------- | --------- |
| 0.1.x   | yes       |
| < 0.1   | no        |

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub: open the Security tab of this repository and choose "Report a vulnerability". If that option is not available to you, open a regular issue titled "security: request for private contact" with no details in it, and I will get in touch.

You should get a first reply within a few days. If the report is confirmed, the fix goes out in a patch release and the advisory is published once users have had a chance to upgrade.
